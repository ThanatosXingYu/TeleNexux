登录与会话安全

Telegram 授权文件与 SQLite 数据库均保存在本地受保护目录。
  • 授权会话不进入 Git、镜像或浏览器存储，文件权限限制为当前用户。
  • API Hash、验证码和云密码不会写入页面或日志。
  • 会话失效后，账号状态会持久化为已掉线，重新授权成功后才恢复在线。
